# SPK.ctf-2026 — пакет заданий (jeopardy)

**Формат:** jeopardy · **Категории:** Web, Crypto, Forensics, Steganography, Reverse Engineering
**Сетка:** 2×Easy (100), 2×Easy-Medium (200), 2×Medium (300), 2×Hard (400), 2×Insane (500) в каждой категории; значения в скобках — **Initial** динамической стоимости.
**Формат флага:** `SPKctf{english_snake_case}`. Флаги не раскрываются в описаниях.
**Стиль:** образовательный, изолированные лабораторные среды, атаки только на сервисы самого CTF.
**Талисман:** СПКашка — парнишка, который обитает на портале и в каждом задании.

**Тип заданий в CTFd:** `dynamic` для всех 50 (dynamic-value), а тип флага — `static` с точным совпадением.

| Сложность | Initial | Decay | Minimum |
|---|---:|---:|---:|
| Easy | 100 | 30 | 40 |
| Easy-Medium | 200 | 25 | 80 |
| Medium | 300 | 20 | 120 |
| Hard | 400 | 15 | 160 |
| Insane | 500 | 10 | 200 |

`Decay` задаёт скорость снижения стоимости при решениях (фактическая кривая зависит от выбранного алгоритма динамической оценки CTFd). Минимум — нижняя граница баллов. В сводной таблице колонка **Initial** показывает стартовую, а не фиксированную цену. Подсказки раздела 8 **сохранены только для организаторов**: текущий импорт API не должен создавать, менять или удалять подсказки. Указания «за 50% стоимости» ниже исторические и не означают, что подсказки доступны игрокам.

**Адрес портала:** `https://ctf.spk.ru` → `192.168.0.46` через локальный DNS; HTTPS обслуживает Docker Nginx с внутренним TLS-сертификатом `LABSEC63-Root-CA`. Сервисы Web `http://<host>:8001–8010` и Crypto `:8106`, `:8109` — отдельные лабораторные сервисы; `<host>` при импорте заменяется реальным адресом, достижимым участникам.

**3. Сложность и баллы:** Hard — 400 очков (Initial; тип CTFd: Dynamic)  
**1. Название:** Гадание на SQL

**4. Описание для игроков:**

Оракул портала отвечает только двумя словами: «найдено» или «пусто». Содержимого не показывает никогда. Но он признался, что видит таблицу `secret`, где лежит флаг в единственной строке.

**5. Необходимые файлы / сервис:** Веб-сервис (Docker, порт 8007).Ссылка для подключения: `http://<host>:8007/search`.

**6. Пошаговое решение (для организатора):**

1. Убедиться, что внедрение есть: `q=test' AND '1'='1` — найдено; `' AND '1'='2` — пусто (boolean-based blind).
2. Определить длину: `q=x' AND (SELECT LENGTH(flag) FROM secret)=N -- ` перебором (N=24).
3. Извлекать посимвольно: `q=x' AND SUBSTRING((SELECT flag FROM secret),{i},1)='{c}' -- `.
4. Автоматизировать перебор скриптом (requests + словарь charset) — получить `SPKctf{...}`.`

**7. Точный флаг:** `SPKctf{blind_sql_3xtr4ction}`

**8. Подсказки:**
- Подсказка 1: Ответы только «да/нет» — используйте условие AND и сравнение символов.
- Подсказка 2 (за 50% стоимости): Для ускорения используйте SUBSTRING + бинарный поиск диапазоном символов.

**9. Инструменты участника:** Python (requests), Burp Intruder, sqlmap (опционально).

**10. Развертывание:** Docker: web/web07_blind_sqli (Flask + SQLite, порт 8007, GET /search?q=). Флаг в таблице secret.
